# ALEXANDRE JORGE MANO · Maputo

Site de Alexandre Jorge Mano, com o desenho EXATO do site JERRY
(mesmo código, mesmo fundo escuro, mesmo dourado, mesmo hero em ecrã
inteiro com "Descer", mesmas coleções com cartões em octógono, mesmo
rodapé) — só mudaram o homem, as fotografias, os textos e os links.

O scroll já vem corrigido como no JERRY (data-lenis-prevent no #app +
scroll-fix.js), por isso a página desce com o scroll normal do telemóvel.
