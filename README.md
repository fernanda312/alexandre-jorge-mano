# ALEXANDRE JORGE MANO · Maputo

Site pessoal de Alexandre Jorge Mano, fundador e CEO da AJMANO Consultores,
com o visual do site JERRY (fundo escuro, dourado champanhe, títulos em
serifada maiúscula) mas construído de raiz para ser robusto no telemóvel:
scroll nativo (sem scroll suave a bloquear a página), secções empilhadas
verticalmente e fotografias sempre inteiras, sem cortes e sem zoom.

## Ficheiros

- `index.html` — a página inteira, em português
- `css/style.css` — o desenho (telemóvel primeiro)
- `js/main.js` — só o menu; o scroll é o nativo
- `images/` — as 6 fotografias enviadas, copiadas sem qualquer corte,
  redimensionamento ou zoom (ficheiros originais, verificados por hash)

## Editar

Mude os textos em `index.html` e troque as fotografias em `images/`
mantendo os mesmos nomes de ficheiro. Não é preciso tocar no CSS nem no JS.
